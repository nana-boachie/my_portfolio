How to repair a drive using Diskpart

A step-by-step guide to fixing common drive problems with the Windows Diskpart utility.

Introduction

Diskpart is the command-line disk partitioning tool built into Windows. It gives you precise control over disks, partitions and volumes, and it often works when graphical tools fail. This guide shows how to use it to clean and rebuild a corrupt drive, mark partitions active and extend volumes.

Back up first

Diskpart commands can permanently delete data if used incorrectly. Back up anything important before you start, and double-check the disk number before every command.

1 Open Command Prompt as administrator

  1. Open the Start menu and type cmd.
  2. Right-click Command Prompt.
  3. Select Run as administrator.

2 Launch Diskpart

diskpart

This opens the Diskpart prompt, where you'll type every command that follows.

3 List and identify your disks

list disk

This shows every connected disk with its number, size and status. Note the number of the disk you want to work on; the size is the easiest way to tell disks apart.

4 Select the target disk

select disk 1

Replace 1 with your disk's number. Diskpart confirms with "Disk 1 is now the selected disk."

5 Check the partition layout

list partition

This lists the partitions on the selected disk with their numbers, sizes and types.

6 Fix the problem

Pick the approach that matches your issue.

A. Clean and rebuild a corrupt disk

If the disk is badly corrupted and you're willing to lose everything on it:

clean
create partition primary
format quick fs=ntfs
assign letter=E

This wipes the partition table, creates one primary partition, formats it as NTFS and assigns drive letter E. Use any free letter you like.

B. Recover a deleted partition

Diskpart can't undelete partitions. If a partition was deleted by mistake, stop writing to the disk and use a recovery tool such as the free, open-source TestDisk, which can scan for and restore lost partitions.

C. Fix file system errors

Diskpart doesn't repair file systems. Exit Diskpart and run chkdsk on the drive instead (replace E: with your drive letter):

chkdsk E: /f

D. Mark a partition as active

On older MBR disks, the boot partition must be marked active:

select partition 1
active

7 Extend a partition into unallocated space

If there's unallocated space directly after a volume, you can grow the volume into it:

select volume E
extend

That uses all the adjacent free space. To add a specific amount in megabytes instead:

extend size=10240

This adds 10 GB (10,240 MB).

8 Exit Diskpart

exit

9 Verify the repair

Open File Explorer and check that the drive is accessible. If you still have problems:

  1. Run chkdsk E: /f to check and fix file system errors.
  2. Open Disk Management (right-click the Start button) to check the disk's status visually.

Conclusion

Diskpart is a reliable tool for rebuilding drives when graphical utilities fail. Use it carefully, always back up first, and pair it with chkdsk and a recovery tool like TestDisk when you need to repair data rather than wipe it.
